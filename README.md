Please create a csv file called 'secretstuff.csv' in the same directory as app.py. Inside this csv file, in the first and second lines respectively, insert:
Secret key, \*\*secret key provided\*\*
API key, \*\*API key provided\*\*

![alt text]([exampleofsecretstuffcsfile.PNG))

## Which file to run
Run the __app.py__ file. The rest are either just for testing or model/package files.

## IMPORTANT FOR BEST ANALYSIS
Make sure that the entire person is visible in all parts of the video. This means that it the video will have to be edited to cut out the part where the user starts and backs up, and also the part where the user finishes and approaches the camera to end. The video should essentially start and end with the whole person visible, otherwise it will crash.

## OTHER GENERAL INFO
In the runs/pose folder, images will be saved; after the application is finished running, feel free to delete them, however leave at least one.
